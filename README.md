Веб-приложение на Python для для анализа банковских операций Автор: Кириленко Юлия stanislavovnajuli987@gmail.com

Установка:
Клонируйте репозиторий:
git clone https://github.com/Yuliya987/PythonProjectCurs1
Установите зависимости:
pip install -r requirements.txt
Использование:
Откройте приложение в вашем веб-браузере.
Введите данные и получите ответ от программы
Использование разработанных функций:
Веб-страницы. Страница "Главная" Функция принимает строку с датой и временем, возвращает по каждой карте топ-5 транзакций по сумме платежа, курс валют, стоимость акций

Сервисы. Инвесткопилка Позволяет копить через округление ваших трат.

Отчеты. Траты в рабочий/выходной день Функция выводит средние траты в рабочий и в выходной день за последние три месяца (от переданной даты).
